# 로또

사용자가 구입 금액을 입력하면, 해당 금액만큼 로또를 발행하고 **당첨 결과와 수익률을 계산**하는 **로또 발매기 프로그램**이다.  

- 로또 번호의 범위는 **1~45**이며, **중복되지 않는 6개의 숫자**로 구성된다.  
- 당첨 번호는 6개, **보너스 번호는 1개**를 입력받는다.  
- 구입한 로또와 당첨 번호를 비교하여 **1등부터 5등까지의 당첨 내역과 총 수익률**을 계산한다.

---

## 입출력 요구 사항

### 입력
1. 로또 구입 금액  
   - 1,000원 단위로 입력하며, 1,000으로 나누어떨어지지 않으면 예외 발생.  
```
14000
```  

2. 당첨 번호  
   - 쉼표(`,`)로 구분된 6개의 숫자를 입력.  
```markdown
1,2,3,4,5,6
```  

3. 보너스 번호  
   - 1개의 숫자를 입력.  
```markdown
7
```

---

### 출력
1. 발행한 로또 수량 및 각 로또의 번호 (오름차순 정렬)
    ```text
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    ...
    ```
2. 당첨 통계 및 각 등수별 당첨 개수
    ```text
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
3. 총 수익률 (소수점 둘째 자리 반올림)
    ```text
    총 수익률은 62.5%입니다.
    ```
4. 예외 발생 시 출력 형식
    ```text
    [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
    ```

## 기능 목록

### 1. 구입 금액 입력
- [ ] 콘솔로 구입 금액을 입력받는다.


### 2. 로또 발행
- [ ] 입력받은 금액에 따라 발행할 로또 개수를 계산한다.
- [ ] 각 로또는 1~45 사이의 중복되지 않은 6개 숫자로 구성된다.

### 3. 당첨 번호 입력
- [ ] 쉼표(`,`)로 구분된 6개의 숫자를 입력받는다.
- [ ] 1~45 범위 외 숫자 입력 시 예외 발생.
- [ ] 숫자 중복 시 예외 발생.

### 4. 보너스 번호 입력
- [ ] 1개의 숫자를 입력받는다.
- [ ] 1~45 범위를 벗어나면 예외 발생.
- [ ] 당첨 번호와 중복되면 예외 발생.

### 5. 당첨 결과 계산
- [ ] 각 로또를 당첨 번호와 비교하여 일치 개수를 계산한다.
- [ ] 등수별 당첨 횟수를 집계한다.

### 6. 수익률 계산
- [ ] 당첨 금액의 총합을 구입 금액으로 나눈다.
- [ ] 소수점 둘째 자리까지 반올림하여 출력한다.

### 7. 결과 출력
- [ ] 등수별 당첨 결과를 출력한다.
- [ ] 총 수익률을 출력한다.

### 8. 예외 처리
- [ ] 잘못된 입력 시 `IllegalArgumentException` 발생.
- [ ] `[ERROR]`로 시작하는 에러 메시지를 출력한다.
- [ ] 예외 발생 시 해당 입력 단계부터 다시 입력을 받는다.

## 프로그래밍 요구 사항
- `Java 21`에서 실행 가능해야 한다.
- `System.exit()` 사용 금지.
- 메서드 들여쓰기 `depth`는 최대 2단계까지만 허용.
- `else`, `switch/case`, 3항 연산자 사용 금지.
- 한 메서드는 한 가지 일만 수행해야 한다.
- `Enum`을 활용하여 당첨 등수와 상금을 관리한다.
- UI 로직을 제외한 핵심 기능은 `JUnit 5`와 `AssertJ`로 테스트를 작성한다.

### Lotto 클래스 사용
- 제공된 Lotto 클래스를 사용하여 구현해야 한다.
- Lotto에 numbers 이외의 필드(인스턴스 변수)를 추가할 수 없다.
- numbers의 접근 제어자인 private은 변경할 수 없다.
- Lotto의 패키지를 변경할 수 있다.
```java
public class Lotto {
private final List<Integer> numbers;

    public Lotto(List<Integer> numbers) {
        validate(numbers);
        this.numbers = numbers;
    }

    private void validate(List<Integer> numbers) {
        if (numbers.size() != 6) {
            throw new IllegalArgumentException("[ERROR] 로또 번호는 6개여야 합니다.");
        }
    }

}
```
